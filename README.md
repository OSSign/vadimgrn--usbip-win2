# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [vadimgrn/usbip-win2](https://github.com/vadimgrn/usbip-win2/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [vadimgrn/usbip-win2](https://github.com/vadimgrn/usbip-win2).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/vadimgrn--usbip-win2/actions).
